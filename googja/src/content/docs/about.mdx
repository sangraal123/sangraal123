# プロダクトを、企画から公開後まで。

AIエージェントを活用し、企画、UI実装、バックエンド連携、CI/CD、ストア公開まで一貫して担当するクロスプラットフォームエンジニアです。
</div>

個人プロジェクトではFlutter、チーム開発ではExpoを中心に使用しています。単に画面を実装するだけでなく、Firebaseによるバックエンド・分析基盤、Google Play・App Storeへの提出、公開後の改善までを一つの工程として扱います。

## 開発の考え方

新しいアイデアを動く形にするプロトタイピングと、公開可能な品質へ持っていくビルドの両方を重視しています。AIには判断を丸投げせず、調査、仕様化、実装、レビュー、テストの各段階で役割を分け、成果物を検証しながら進めます。
