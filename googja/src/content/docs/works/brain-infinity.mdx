## 技術構成

| 領域 | 採用技術 |
| --- | --- |
| UI / App | Flutter、Material 3、GoRouter |
| State | Provider、Flutter Bloc |
| Data | SharedPreferences、JSON question sets |
| Analytics / Ads | Firebase Analytics、Google Mobile Ads |
| Quality | flutter_test、Mockito、レスポンシブ回帰テスト |
| Delivery | GitHub Actions、App Store Connect、Google Play Console |

## 設計上の判断

- スマートフォンだけでなく、タブレット縦横・デスクトップでも画面幅と向きを見てレイアウトを切り替えています。
- 年齢確認が完了する前に分析・広告リクエストを開始しない構成にし、子ども向け設定を最初のリクエストから適用します。
- Webデモではゲーム体験を優先し、ディスプレイ広告をアプリ画面の外へ移しました。
- 日本語・英語、テーマ、文字倍率、ストア指定サイズを組み合わせたスクリーンショットをテストから生成します。
