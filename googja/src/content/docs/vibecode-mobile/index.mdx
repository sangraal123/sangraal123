## 学習ロードマップ

全8フェーズ・40記事で、習慣記録アプリ「HabitFlow」を段階的に作ります。まずはローカル保存だけのMVPを動かし、必要に応じて広告・課金・クラウド連携などを追加します。巻末には、公開後の検証と運用を扱う補講も追加しています。

:::note[公開前にセキュリティ編を確認してください]
セキュリティ編は巻末の参照先です。初回のテスト配布・ストア公開の**前**に読み、認証・広告・課金・AI機能を追加するたびに該当項目を再確認してください。
:::

:::

## 補講：運用・検証編

公開できるアプリは、画面が表示されるだけでなく、失敗したときに安全に戻れ、更新後も状態を確認できます。Firebase Emulator、EAS Update、本番公開後のチェックを、既存のフェーズと独立して学べるようにしました。
